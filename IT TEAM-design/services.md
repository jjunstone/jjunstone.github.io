## 기본 9개 서비스 (확정)

### 1. 계정 및 신원 관리 (IAM)
담당: 보안팀장 (정책), 보안사원 + 지원인력 (운영)
정기: 월간 활동 계정 감사, 권한 만료 검토
규제: 개인정보보호법 제29조, ISO 27001 A.9.2

### 2. 데이터베이스 운영
담당: DBA팀장 (정책), DB사원 (운영)
정기: 일일 백업 검증, 주간 성능 분석, 월간 보안 패치
규제: 개인정보보호법 제30조, ISO 27001 A.12.4

### 3. 방화벽 및 네트워크 분리
담당: 네트워크과장 (정책), 네트워크사원 (운영)
정기: 주간 규칙 감사, 월간 성능 검토
규제: 전자금융거래법 제22조, ISO 27001 A.13.1

### 4. 서버 및 인프라 운영
담당: 서버과장 (정책), 서버사원 (운영)
정기: 일일 리소스 모니터링, 주간 패치 적용
규제: ISO 27001 A.12.2

### 5. 보안 모니터링 및 사건 관리
담당: 보안팀장 (정책), 보안사원 + 지원인력 (운영), 외주 SOC (24/7 모니터링)
정기: 일일 보안 로그 검토, 주간 위협 분석
규제: 개인정보보호법 제29조, ISO 27001 A.12.4

### 6. 클라우드 및 SaaS 관리
담당: 인프라관리사원 (운영), 서버과장 (승인)
정기: 월간 클라우드 비용 검토, 분기 규정 준수 감사
규제: 전자금융거래법 제21조의2

### 7. 백업 및 재해복구
담당: 인프라관리사원 (운영), DBA팀장 (검증), 부분 외주 (인프라)
정기: 일일 백업 로그 검증, 월간 복구 드릴, 분기 DR 테스트
규제: 개인정보보호법 제30조, ISO 27001 A.12.3

### 8. 인증서 및 암호화
담당: 보안팀장 (정책), 보안사원 + 지원인력 (운영)
정기: 월간 인증서 만료 확인, 분기 암호화 키 감사
규제: 개인정보보호법 제30조, ISO 27001 A.10.1

### 9. IT 자산 및 라이선스 관리
담당: 인프라관리사원 (운영), 서버과장 (승인), 부분 외주 (서비스데스크)
정기: 월간 자산 인벤토리, 분기 라이선스 감사
규제: ISO 27001 A.15.1

## 신규 11개 서비스 (Phase 4)

### 10. 원격접속 (VPN)
담당: 네트워크과장 (기술운영), 보안팀장 (접속정책), IAM (사용자인증)
정기: 주간 VPN 접속 로그 검토, 월간 정책 감사
요청: 원격접속 승인, MFA 설정, 협력업체 접속
장애: VPN 연결 장애, 인증 실패, 성능 저하
규제: ISO 27001 A.9.1 (사용자 인증), A.13.1 (접근제어)

### 11. 엔드포인트 보안 (EDR/UEM)
담당: 보안팀장 (정책), 보안사원 + 지원인력 (운영), 솔루션담당자 (기술)
정기: 일일 EDR 위협 감시, 주간 취약점 스캔, 월간 UEM 정책 검토
요청: 단말 등록, 정책 변경, 격리 승인
장애: 악성 프로세스 탐지, 단말 격리, 복구
규제: ISO 27001 A.12.2 (시스템 관리)

### 12. DNS 및 IPAM (IP 주소 관리)
담당: 네트워크과장 (정책), 네트워크사원 (운영)
정기: 주간 DNS 레코드 검증, 월간 IP 주소 공간 분석
요청: DNS 레코드 추가, IP 대역 변경, DHCP 설정
장애: DNS 응답 실패, IP 중복, 라우팅 오류
규제: ISO 27001 A.13.1 (네트워크 관리)

### 13. 특권계정 관리 (PAM)
담당: 보안팀장 (정책), 보안사원 + 지원인력 (운영), 솔루션담당자 (기술)
정기: 월간 특권계정 감시, 분기 접근 검토, 분기 세션 기록 감사
요청: 임시 특권계정 발급, 비밀번호 회수, 접근 승인
장애: 세션 녹화 실패, 계정 잠금, 감시 중단
규제: ISO 27001 A.9.2 (특권계정 관리)

### 14. 로그 및 SIEM (보안정보이벤트관리)
담당: 보안팀장 (정책), 보안사원 + 지원인력 (운영), 외주 SOC (분석)
정기: 일일 보안 이벤트 검토, 주간 위협 분석, 월간 리포트
요청: 로그 조회, 사건 조사, 법적 보류 증거 수집
장애: 로그 수집 중단, SIEM 저장소 가득참, 분석 지연
규제: ISO 27001 A.12.4 (로깅 및 모니터링)

### 15. 인증서 관리 고도화
담당: 보안팀장 (정책), 보안사원 + 지원인력 (운영)
정기: 월간 인증서 만료 확인, 분기 자동 갱신 검증
요청: 신규 인증서 발급, 키 로테이션, 정책 변경
장애: 인증서 만료, 자동 갱신 실패, 키 손상
규제: ISO 27001 A.10.1 (암호화)

### 16. DLP (데이터손실방지)
담당: 보안팀장 (정책), 보안사원 + 지원인력 (운영)
정기: 주간 DLP 정책 위반 검토, 월간 데이터 분류 감사
요청: 데이터 분류 변경, 정책 예외 승인
장애: 중요 데이터 유출 감지, 시스템 오류, 정책 업데이트 실패
규제: 개인정보보호법 제30조 (개인정보 보호)

### 17. ITSM (변경·문제·요청 관리)
담당: DBA팀장 (조율), 서비스데스크 (외주), 각 팀 (실행)
정기: 월간 변경 리뷰, 분기 문제 분석, 월간 요청 성과
요청: IT 서비스 요청 (PC 설치, 계정 초기화 등), 변경 신청
장애: 긴급 변경 절차, 심각 문제 대응
규제: ISO 27001 A.12.1 (변경 관리)

### 18. 클라우드 비용 및 리소스 최적화
담당: 인프라관리사원 (운영), 서버과장 (승인)
정기: 월간 클라우드 비용 분석, 분기 리소스 사이징 검토
요청: 인스턴스 업그레이드, 예약 인스턴스 구매, 비용 할당 변경
장애: 비용 폭증, 용량 부족
규제: 없음 (운영 효율성)

### 19. 외주 솔루션 관리 및 조율
담당: DBA팀장 (정책), 각 팀장 (기술 조율), 외주 담당자 (지원)
정기: 월간 외주 성과 검토, 분기 SLA 검증
요청: 기술 지원 요청, 이슈 보고, 개선 사항
장애: 외주 체계의 중단, 우선도 이슈
규제: 없음 (계약 기반)

### 20. 운영 리포팅 및 규제 대응
담당: DBA팀장 (총괄), 각 팀장 (데이터 제공)
정기: 월간 경영진 리포트, 분기 규정 준수 감사, 연간 외부 감사 대응
요청: 감사 자료 요청, 정책 검증
장애: 감사 오류, 문서 누락
규제: ISO 27001, ISMS-P, 개인정보보호법
