# 규제 조항 매핑

## 주의사항

- 조문 번호는 2026-10-19 국가법령정보센터 원문 대조 기준
- 법령상 의무와 내부 보안 기준으로 채택한 사항을 구분하여 표시
  - [법령의무]: 해당 법령·규정이 직접 적용되는 의무
  - [내부채택]: 법적 의무는 아니나 내부 기준으로 채택
- [확인필요]: 조문 번호 또는 적용 대상 여부를 아직 확인하지 못한 항목
- ISO 27001:2022 기준: Annex A에 93개 참조 통제, 4개 주제 영역 (2013년판 14개 도메인과 다름)
- 준수 상태: 통제 매핑 작성 중 (실제 작동 증명은 구현 후 감사에서 검증)

- 8.20 네트워크 보안 -> S3(방화벽), S10(VPN)

## 2. 개인정보보호법

[법령의무] 개인정보를 처리하는 경우 직접 적용

### 제29조 (안전조치 의무)
- 안전성 확보에 필요한 기술적·관리적 조치 의무의 상위 법적 근거
- 관련 서비스: S1(IAM), S5(모니터링)
- 관련 흐름: F01(입사), F02(퇴사), F05(DB접근)

### 시행령 제30조 (안전성 확보조치 - 접근권한)
- 접근 권한 제한, 불필요한 계정 삭제, 접속기록 보관 등
- 관련 서비스: S1(IAM), S14(SIEM)
- 관련 흐름: F01(입사), F02(퇴사)

### 개인정보의 안전성 확보조치 기준 (고시)
- 암호화 저장 및 전송 [확인필요: 해당 고시 조문 번호]
  -> S8(암호화), S15(인증서)
- 백업 및 복구 [확인필요: 해당 고시에 명시적 조문 있는지 확인]
  -> S7(백업DR)
- 접근통제 기술적 조치 [확인필요: 해당 고시 조문 번호]
  -> S1(IAM), S10(VPN)

### 제30조 (법률 - 개인정보 처리방침 공개)
- 처리방침 수립 및 공개 의무
- 관련 서비스: S20(운영리포팅)

주의: 법률 제30조(처리방침)와 시행령 제30조(접근권한)는 다른 조항이다.
암호화·백업의 직접 근거는 법률 제30조가 아니라 안전성 확보조치 기준(고시)에서 확인해야 한다.

## 3. 전자금융감독규정

[법령의무] 금융회사 및 전자금융업자에 적용. 해당 조직이 적용 대상인지 별도 확인 필요.

### 제15조 제1항 제3호 (망분리)
- 내부통신망과 연결된 내부 업무용 시스템의 외부통신망 분리·차단
- 관련 서비스: S3(방화벽), S10(VPN)
- 관련 흐름: F04(방화벽예외)

기존 문서의 전자금융거래법 제22조(망분리) 인용은 잘못된 인용이다.
제22조는 전자금융거래기록의 생성·보존 조항이다.

### 제14조의2 (클라우드컴퓨팅서비스 이용)
- 클라우드 제공자 평가, 업무 연속성 계획, 안전성 확보조치, 위수탁 계약 사항
- 관련 별표: 클라우드 이용 시 준수 사항 상세 규정
- 관련 서비스: S6(클라우드SaaS), S19(외주관리)
- 관련 흐름: F12(클라우드심사)

기존 문서의 전자금융거래법 제21조의2(클라우드) 인용은 잘못된 인용이다.
제21조의2는 정보보호최고책임자 지정 조항이다.

## 4. 전자금융거래법

[법령의무] 금융회사 및 전자금융업자에 적용

### 제22조 (전자금융거래기록의 생성 및 보존)
- 거래 기록 생성 및 보존 의무
- 관련 서비스: S14(SIEM), S2(DB)
- 관련 흐름: F17(로그분석), F24(월간리포트)

## 5. ISMS-P 인증기준

[내부채택] ISMS-P 인증은 일정 규모 이상 정보통신서비스 제공자에게 의무이나,
금융회사의 경우 적용 의무 여부를 별도 확인 필요. 내부 기준으로 채택하는 것은 무관.

### 관리체계 수립 및 운영
- 1.1 관리체계 기반 마련 -> S20(운영리포팅), F13(외부감사)
- 1.4 관리체계 점검 및 개선 -> review/consistency.md

### 보호대책 요구사항
- 2.5 인증 및 권한 관리 -> S1(IAM), S13(PAM)
- 2.6 접근통제 -> S1(IAM), S10(VPN), F05(DB접근)
- 2.7 암호화 적용 -> S8(암호화), S15(인증서)
- 2.8 정보시스템 도입 및 개발 보안 -> F14(기술도입), F06(코드배포)
- 2.10 시스템 및 서비스 보안 관리 -> S11(EDR), S7(백업DR)
- 2.11 사고 예방 및 대응 -> S5(모니터링), F08(보안사건)
- 2.12 재해 복구 -> S7(백업DR), F10(백업훈련)
