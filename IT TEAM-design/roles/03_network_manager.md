# 네트워크과장 역할

## 책임 범위
- 방화벽 및 네트워크 분리 운영
- 네트워크 성능 및 보안 관리
- VPN 및 원격 접근 제어

## 일일 보는 지표
- 네트워크 가용성
- 방화벽 규칙 히트 현황
- 대역폭 사용률
- DDoS 공격 시도 건수

## 주간 정기 업무
- 방화벽 규칙 감사
- 네트워크 성능 검토
- 예외 규칙 일시 만료 확인

## 월간 정기 업무
- 종합 네트워크 감사
- 정책 업데이트 검토
- 용량 계획

## 가장 자주 협업하는 역할
1. 네트워크사원 (일일)
2. 보안팀장 (2회/주)
3. DBA팀장 (예외 규칙)

## 장애 시 첫 행동
1. 방화벽 로그 확인
2. 네트워크 연결성 검사
3. DDoS 또는 공격 여부 확인
4. 보안팀장과 조율
