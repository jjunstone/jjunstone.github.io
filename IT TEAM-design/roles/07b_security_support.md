# 보안팀 지원인력 역할

## 요약
보안팀의 솔루션 운영 및 기술 보조. 팀장과 사원이 수립한 정책을 구현·운영하고 데이터 수집으로 의사결정을 지원.

## 책임 범위
- 보안 솔루션 기술 운영 (IAM, EDR, 방화벽 로그 수집)
- 팀장·사원의 의사결정 지원 (데이터 분석, 리포트 작성)
- 정기 모니터링 및 경보 (휴일/야간 포함)

## 일일 보는 지표
- 보안 솔루션 상태 (IAM, EDR, SIEM)
- 로그 수집 현황
- 경보 건수 및 심각도

## 주간 정기 업무
- 보안 이벤트 로그 정제 및 분류
- 주간 보안 현황 데이터 수집
- 솔루션 업데이트 및 패치 확인

## 월간 정기 업무
- 솔루션 성능 분석 리포트
- 라이선스 및 용량 검토
- 정책 적용 여부 기술 검증

## 운영 철학

### 책임 구분 (RACI)
- **Responsible (실행)**: 이 역할
- **Accountable (결정)**: 보안팀장
- **Consulted (상담)**: 보안사원
- **Informed (통보)**: 기타 팀

### 지원인력의 위치
- 팀장: 정책 수립, 의사결정, 최종 책임
- 사원: 실무 운영, 사건 조사, 사원 지도
- 지원인력: 기술 구현, 모니터링, 보조 분석

### 의사결정 흐름
팀장이 정책 결정 → 사원과 지원인력이 구현 → 지원인력이 데이터 수집 → 팀장·사원이 검증·의사결정

## 협업 관계
- 보안팀장 (일일): 방향 확인, 이슈 보고
- 보안사원 (2-3회/주): 실무 조율
- 네트워크팀 (주 1회): 방화벽 로그
- DBA팀 (주 1회): DB 접근 로그

## 장애 시 첫 행동
1. 솔루션 상태 확인 (온라인·오프라인·성능저하)
2. 기본 재시작 또는 재연결 시도
3. 즉시 보안사원에 보고
4. 사원 지시에 따라 응급 조치 또는 외부 지원 요청

## 요구 기술 스택
- Windows/Linux 기본
- 보안 솔루션 UI (IAM, EDR, SIEM)
- 로그 분석 기본
- 스크립트 (자동화 경험 우대)
