# 서버과장 역할

## 책임 범위
- 서버 인프라 운영 및 성능 관리
- 보안 패치 계획 및 실행
- 클라우드/SaaS 승인 권한 (부)
- IT 자산 승인 권한 (부)

## 일일 보는 지표
- 서버 가용성 및 CPU/메모리 사용률
- 패치 규정 준수 상태
- 디스크 사용률
- 서비스 헬스 상태

## 주간 정기 업무
- 성능 분석
- 용량 계획 검토
- 패치 적용 일정 계획

## 가장 자주 협업하는 역할
1. 서버사원 (일일)
2. DBA팀장 (2회/주)
3. 보안팀장 (패치 승인)
4. 인프라관리사원 (클라우드)

## 장애 시 첫 행동
1. 리소스 사용률 확인
2. 최근 변경사항 검토
3. 서비스 재시작 시도
4. 필요 시 DBA팀장 호출
