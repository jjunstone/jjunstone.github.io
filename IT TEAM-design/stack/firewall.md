# 방화벽 및 네트워크 분리

## 용도
- 네트워크 경계 보안 강화
- DMZ, 내부, 결제 네트워크 분리
- 인바운드/아웃바운드 트래픽 제어
- 무단 접근 방지 (전자금융거래법 제22조)

## 관련 규제 조항
- 전자금융거래법 제22조: 망분리 (외부망 ↔ 내부망)
- ISO 27001 A.13.1: 네트워크 분리
- ISMS-P: 망 분리 요구사항

## 대안 비교

### 옵션 A: Palo Alto Networks
**개요:** 고급 위협 방지 기능
**장점:** 뛰어난 로깅, 위협 탐지 능력
**단점:** 높은 비용, 복잡한 관리
**10명 운영 적합도:** 중간
**규정 준수:** 완전

### 옵션 B: FortiGate (권장)
**개요:** 균형잡힌 성능
**장점:** 좋은 가격/성능, 우수한 로깅, 빠른 학습곡선
**단점:** 중간 수준의 고급 기능
**10명 운영 적합도:** 높음
**규정 준수:** 완전

### 옵션 C: CheckPoint
**개요:** 강력한 보안
**장점:** 금융권 선호, 강력한 규정 준수
**단점:** 높은 비용, 가파른 학습곡선
**10명 운영 적합도:** 중간
**규정 준수:** 완전

## 권장안
**FortiGate**
- 이유: 소규모 팀에 최적 (관리 난이도 vs 기능)
- 비용: Palo Alto 대비 30-40% 저렴
- 학습: 상대적으로 쉬운 관리

## 네트워크 아키텍처 (전자금융거래법 제22조 준수)
- **외부 DMZ**: 인터넷 연결 서비스
- **내부 영역**: 업무 애플리케이션
- **제한 영역**: 데이터베이스, 결제 처리

방화벽이 각 계층 간 트래픽 제어
