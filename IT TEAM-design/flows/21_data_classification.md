# F20: 데이터 분류 및 레이블 지정

## 트리거
신규 데이터셋 생성, 정기 분류 검토

## 단계별 담당 역할
1. 서비스 소유자: 데이터 분류 신청
2. 보안팀장: 데이터 민감도 평가
3. 서비스 소유자: 분류 확인 및 승인
4. 지원인력: 데이터 레이블 지정 (시스템에 적용)
5. 보안팀장: 최종 검증

## 데이터 분류 등급
| 등급 | 예시 | 암호화 | 접근제어 |
|------|------|--------|---------|
| 최상위 | 개인정보, 계약서 | 필수 | 최소한 |
| 상 | 거래 데이터, 재무 | 필수 | 제한적 |
| 중 | 운영 데이터 | 권장 | 팀 내 |
| 하 | 공개 정보 | 선택 | 공개 |
