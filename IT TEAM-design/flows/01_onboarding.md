# 입사 흐름

## 트리거
HR 부서의 신규 입사자 알림 + 직급 및 부서 배정

## 단계별 담당 역할

1. 보안팀장: 입사 알림 수신
2. 보안팀장: Active Directory 계정 생성 (임시 비밀번호)
3. 네트워크과장: 네트워크 접근 그룹 배정
4. DBA팀장: 필요 시 데이터베이스 권한 배정
5. 서버과장: 필요 시 서버 그룹 배정
6. 인프라/DevOps과장: 필요 시 클라우드 리소스 접근 권한 배정
7. 보안팀장: MFA 발급 및 등록
8. 신규 직원: 첫 로그인 시 임시 비밀번호 변경
9. 보안팀장: MFA 등록 완료 확인
10. 모든 접근 내용이 감사 시스템에 기록

## 각 단계의 승인·검증·기록

| 단계 | 승인 | 검증 | 감시로그 |
|------|------|------|---------|
| 1 | HR 승인 | - | 요청 시간 |
| 2 | 보안팀장 | AD 계정 생성 확인 | 계정 생성 시간, 초기화 자동화 |
| 3 | 네트워크과장 | 그룹 추가 확인 | 그룹 배정 로그 |
| 4 | DBA팀장 | 권한 부여 확인 | 권한 부여 타임스탬프 |
| 7 | 보안팀장 | MFA 등록 확인 | MFA 장치 등록 로그 |
| 9 | 보안팀장 | 첫 로그인 성공 확인 | 로그인 기록 |

## 실패 시 처리
- 계정 생성 실패: 재시도, 에러 로그 검토
- MFA 등록 실패: 보안팀장 수동 개입, 벤더 지원
- 접근 확인 실패: 수동 접근 테스트, 권한 재설정

## 남는 감사 증적
- Active Directory 계정 생성 로그
- 그룹 멤버십 변경 기록
- MFA 장치 등록 기록
- 첫 로그인 타임스탐프
- 모든 권한 부여 기록

## 자동화 가능 지점
- HR 시스템 ↔ AD 연동 (자동 계정 생성)
- 직급 코드 ↔ 그룹 자동 배정
- 임시 비밀번호 자동 생성
- MFA 등록 알림 자동 발송
- 입사 체크리스트 자동화
