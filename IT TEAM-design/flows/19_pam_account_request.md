# F18: PAM 특권계정 요청 및 감시

## 트리거
관리자가 서버/DB/방화벽 등 특권계정 접근 필요

## 단계별 담당 역할
1. 요청자: 특권계정 접근 신청 (필요 시스템, 목적, 기간)
2. 직속 상사: 업무 필요성 승인
3. 보안팀장: 접근 정책 검증
4. 솔루션담당자(외주): PAM에 임시계정 생성
5. 요청자: 접근 및 작업 수행
6. PAM: 세션 자동 기록
7. 보안팀장: 세션 검토 및 종결

## PAM 정책
- 모든 특권계정 접근은 보안팀 승인 필수
- 최대 세션 시간: 4시간 (초과 시 수동 승인)
- 모든 세션은 비디오 기록 (60일 보관)
- 세션 로그: 입력 명령, 파일 변경 기록

## 각 단계의 검증·기록
| 단계 | 검증 | 기록 |
|------|------|------|
| 2 | 승인자 확인 | 승인 기록 |
| 3 | 정책 준수 | 정책 검증 기록 |
| 4 | 계정 생성 | 계정 생성 로그 |
| 5 | 세션 시작 | 접속 시간 |
| 7 | 세션 검토 | 종결 시간 |

## 남는 감사 증적
- 특권계정 접근 요청 및 승인
- 세션 시작·종료 시간
- 세션 비디오 기록 (60일)
- 입력 명령 로그
- 파일 변경 기록
