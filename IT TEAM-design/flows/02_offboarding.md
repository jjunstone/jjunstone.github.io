# 퇴사 흐름

## 트리거
HR 부서의 퇴사자 알림 + 퇴사 예정일

## 단계별 담당 역할

1. HR: 모든 IT 팀에 퇴사 알림
2. 보안팀장: 퇴사 예정일에 Active Directory 계정 비활성화
3. 보안팀장: 모든 API 키 및 토큰 폐지
4. 네트워크과장: 네트워크 접근 권한 제거
5. DBA팀장: 데이터베이스 접근 권한 폐지
6. 서버과장: 서버 접근 권한 제거
7. 인프라관리사원: 회사 기기 회수 및 데이터 삭제
8. 보안팀장: 모든 접근 제거 확인
9. 감시 시스템에 퇴사 기록 생성

## 각 단계의 승인·검증·기록

| 단계 | 승인 | 검증 | 감시로그 |
|------|------|------|---------|
| 1 | HR 확인 | - | 퇴사 알림 수신 시간 |
| 2 | 보안팀장 | AD 계정 비활성화 확인 | 계정 비활성화 시간 |
| 3 | 보안팀장 | 토큰 폐지 확인 | 폐지된 토큰 목록 |
| 7 | 인프라관리사원 | 기기 회수 서명 | 회수 일시, 삭제 확인 |
| 8 | 보안팀장 | 모든 접근 제거 확인 | 최종 검증 타임스탐프 |

## 실패 시 처리
- 계정 비활성화 실패: 수동 비활성화
- 남은 토큰 발견: 즉시 폐지
- 기기 미반납: HR과 조율, 대체 수수료 처리
- 법적 보류 필요: DBA팀장 지시, 데이터 보존

## 남는 감사 증적
- Active Directory 계정 비활성화 기록
- API 키 폐지 기록
- 접근 권한 제거 기록
- 기기 회수 서명 및 이력
- 데이터 삭제 확인서

## 자동화 가능 지점
- HR 시스템 ↔ AD 연동 (자동 비활성화)
- 토큰 자동 폐지
- 기기 추적 및 회수 알림
- 퇴사 체크리스트 자동화
