# F14: 원격 접속 요청 및 승인

## 트리거
직원의 재택근무 필요 또는 협력업체의 VPN 접속 요청

## 단계별 담당 역할
1. 요청자: 신청서 제출 (재택근무 기간, 필요 시스템)
2. 직속 상사: 업무 필요성 승인
3. 보안팀장: 보안 정책 검증 (MFA 필수, 시간 제한 등)
4. 네트워크과장: VPN 기술 가능 여부 검토
5. IAM담당(보안사원): 사용자 인증 설정
6. 네트워크사원: VPN 계정 생성 및 활성화
7. 요청자: 접속 테스트 및 확인

## 각 단계의 승인·검증·기록
| 단계 | 담당 | 검증 | 감시로그 |
|------|------|------|---------|
| 1-2 | 직속상사 | 업무 필요성 | 신청 기록 |
| 3 | 보안팀장 | MFA, IP 제한 정책 | 정책 검증 기록 |
| 4 | 네트워크과장 | VPN 용량, 보안 | 기술 검토 기록 |
| 5 | 보안사원 | AD 계정, MFA 등록 | 인증 설정 로그 |
| 6 | 네트워크사원 | VPN 접속 성공 | VPN 계정 생성 로그 |
| 7 | 요청자 | 실제 접속 테스트 | 접속 성공 로그 |

## 실패 시 처리
- MFA 등록 실패: 보안사원이 재시도 또는 수동 설정
- VPN 접속 실패: 네트워크과장이 구성 검토
- 보안 정책 불일치: 보안팀장이 예외 승인 또는 거부

## 남는 감사 증적
- VPN 접속 요청 기록 및 승인자 서명
- 보안 정책 검증 기록
- MFA 등록 타임스탐프
- VPN 계정 생성 로그
- 접속 성공 시간 기록

## 자동화 가능 지점
- HR 시스템 → 재택근무 승인 자동 연동
- 자동 MFA 배포
- VPN 계정 자동 생성 (정책 기반)
- 기간 만료 시 자동 회수
