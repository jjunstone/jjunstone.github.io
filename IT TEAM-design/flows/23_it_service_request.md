# F22: IT 서비스 요청 (표준 티켓)

## 트리거
직원의 IT 지원 요청 (PC 설치, 계정 초기화, 소프트웨어 설치 등)

## 단계별 담당 역할
1. 요청자: 서비스데스크(외주)에 요청 제출
2. 서비스데스크: 요청 분류 및 우선도 결정
3. 해당 팀: 작업 수행
4. 요청자: 완료 확인
5. 서비스데스크: 티켓 종결

## SLA
| 요청 유형 | 목표 완료 시간 |
|----------|--------------|
| 긴급 (계정 잠금) | 1시간 |
| 높음 (PC 문제) | 4시간 |
| 중간 (소프트웨어) | 1일 |
| 낮음 (자문) | 3일 |
